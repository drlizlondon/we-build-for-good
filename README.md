# We Build For Good: Digital Flagship

> *"We build with AI, for ourselves and for others."*

Official digital flagship and public thesis of **We Build For Good Limited**, London.

- **Primary Domain**: [webuildforgood.com](https://webuildforgood.com)
- **Secondary Domain**: [webuildforgood.co.uk](https://webuildforgood.co.uk) (301 redirect)
- **Contact**: `hello@webuildforgood.com`

## Architecture
- Static, zero-dependency, ultra-fast single page application.
- GPU-accelerated motion choreography with full `prefers-reduced-motion` compliance.
- Complete OpenGraph, Twitter Cards, and Schema.org JSON-LD structured data for Google Knowledge Graph & AI Answer Engines (Perplexity, ChatGPT Search, Claude).

## Deployment
Deployable in 1 click to Cloudflare Pages, GitHub Pages, or Vercel.
